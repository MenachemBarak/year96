# Year96

Year96 is a design for an agentic operating system. A human's desire becomes a thread that never closes. Agent Ownerships own it and keep learning the human's mental model. Duties turn it into work, Builders execute it, and independent verifiers prove it is done.

This repository holds the design. There is no code yet.

- `docs/YEAR96_INTRO.md`, `docs/YEAR96_SPEC.md` and `docs/YEAR96_Vision.md` are the owner's source documents.
- `docs/YEAR96_TECHNICAL_ARCHITECTURE.md` is the technical architecture. It was reviewed in rounds where every model reviewed every aspect.
- `docs/research/` holds the 15 research reports behind the architecture, and the review log.
